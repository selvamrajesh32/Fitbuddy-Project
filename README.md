# 🏋️ FitBuddy – Fitness & Workout Assistant

FitBuddy is a web-based fitness application developed using **Python, FastAPI, HTML, CSS and JavaScript**. It helps users access fitness-related information, workout guidance and a simple interactive fitness interface.

## 🚀 Features

- 🏠 User-friendly Home Page
- 💪 Workout & Fitness Guidance
- 🥗 Fitness/Diet Information
- 📊 Simple fitness interaction
- 📱 Responsive Web Interface
- ⚡ FastAPI backend
- 📚 Automatic API documentation using Swagger UI

## 🛠️ Technologies Used

### Backend
- Python
- FastAPI
- Uvicorn

### Frontend
- HTML5
- CSS3
- JavaScript
